# Balaton Park media bank

Everything Roy has sent into the Claude chats, kept at the size it arrived so
a later session can use it without asking him for it again.

This branch is **not** served by GitHub Pages - Pages serves `main`. It exists
only to hold files. Nothing here is referenced by any of the sites; the sites
carry their own web-sized copies.

```
photos/2026-11-24/   the 24 Nov batch, original resolution
photos/earlier/      earlier uploads, by their upload id
logos/               client marks - originals and the white knockouts
drawings/            lounge floor plans (PDF)
video/              1080p masters (see the note at the bottom)
```
